# Archive

This directory contains version-controlled artifacts that were once curated or were otherwise intentionally preserved and have since been retired, superseded, or invalidated.

It is **not** a mirror of closed Issues. GitHub's open and closed Issues remain the repository's working memory and should stay searchable there.

When moving a curated idea from `ideas/` to `archive/`:

1. open a governance or proposal-linked pull request;
2. preserve the document's original content and history;
3. add `archived_on` and `archive_reason` to its front matter;
4. add `superseded_by` when another curated idea replaces it;
5. explain the human decision in the pull request;
6. update the source Issue to `status:archived` after merge.

Archival is not deletion and not punishment. It records that the repository's current judgment changed.
