# Decision records

This directory records durable decisions about the repository's architecture, workflow, and governance.

Decision records use the following states:

- `Accepted`
- `Superseded by NNNN`
- `Deprecated`

Each record should contain context, decision, consequences, rejected alternatives, and review triggers. Significant changes to repository principles, promotion authority, metadata, licensing, or contribution mechanics should update an existing record or add a new one.
