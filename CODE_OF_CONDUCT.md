# Code of Conduct

## Standard

Ideas Worth Building is a place for rigorous, generous criticism of ideas. Participation requires respect for people, intellectual honesty, and care for the shared signal-to-noise ratio.

Expected behaviour includes:

- critique the proposal, evidence, assumptions, and design—not the contributor's intelligence or motives;
- steelman before dismissing;
- make room for incomplete, unconventional, playful, non-commercial, and hard-to-classify ideas;
- distinguish facts, assumptions, and speculation;
- cite claims and correct errors openly;
- preserve attribution;
- disclose material conflicts of interest and agent assistance;
- accept that promotion is selective and that disagreement is normal;
- avoid flooding the repository with repetitive or generated content.

Unacceptable behaviour includes:

- harassment, threats, stalking, discrimination, sexualized conduct, or personal attacks;
- publishing private or identifying information without permission;
- fabricating evidence, users, quotations, research, or experiments;
- plagiarism or deliberate removal of contribution credit;
- coordinated vote manipulation or covert commercial promotion;
- repeated generic model-generated praise, rejection, or idea lists;
- submitting confidential, proprietary, security-sensitive, or unauthorized material;
- using critique as a pretext for hostility or gatekeeping people rather than curating ideas.

## Scope

This Code applies to Issues, comments, pull requests, repository files, linked community spaces operated by the project, and public conduct undertaken while representing the project.

## Enforcement

Maintainers may edit or remove content, request corrections or disclosure, change labels, close or lock threads, restrict participation, or ban contributors. Enforcement should be proportionate and should record a reason when doing so would not expose a reporter or private information.

For an urgent or sensitive report, contact the repository owner through a private contact method listed on their GitHub profile. Do not open a public Issue containing private evidence.

Good-faith disagreement about whether an idea is worth building is not a Code of Conduct violation. Harassment, deception, and repository flooding are.
