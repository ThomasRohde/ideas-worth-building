# Principles

These principles govern how Ideas Worth Building receives, develops, and curates proposals. They are deliberately stronger than workflow guidance: when convenience, automation, metrics, or convention conflict with a principle, the principle should usually win.

1. [Open entrance, demanding boundary](01-open-entrance-demanding-boundary.md)
2. [No problem-statement theatre](02-no-problem-statement-theatre.md)
3. [Depth over volume](03-depth-over-volume.md)
4. [Epistemic honesty](04-epistemic-honesty.md)
5. [Distinctiveness and taste](05-distinctiveness-and-taste.md)
6. [Agents assist; humans decide](06-agents-assist-humans-decide.md)
7. [Build to learn before building to scale](07-build-to-learn.md)
8. [Preserve lineage and share credit](08-lineage-and-credit.md)
9. [Critique the strongest version](09-strong-critique.md)
10. [Curated memory is revisable](10-revisable-curation.md)

Changes to these principles require a governance Issue and a pull request that records the rationale in [`decisions/`](../decisions/).
